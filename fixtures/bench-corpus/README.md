# RunbookBench pilot seed corpus

This directory contains 12 deliberately small, fixture-sized cases: two authentic normative, two authentic operational, two structured contracts, three constructed golden, and three adversarial mutations. The authentic cases retain public provenance metadata; constructed and adversarial cases are explicitly synthetic. This is a pilot seed, not evidence of general SOP understanding.

Candidate files for `runbookbench eval` are named `<id>.json` and use the `BenchmarkCandidate` shape exported by `@runbook/bench`.
